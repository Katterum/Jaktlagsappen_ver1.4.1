# Jaktlaget 1.4.1

- Ingen dubbel jaktårsinformation eller datumintervall på startsidan.
- Mer-sidan visar registrering till vänster och statistik till höger.
- Genomförda jakter, jaktdagar, viltobservationer och flockstorlek.
- Kassationer är helt separerade från ordinarie statistik.
- Fem angivna fällda djur och fyra platser ingår vid en helt ny installation.
- Befintlig lokal data migreras från 1.4.0, 1.3.1 eller 1.2.2 utan att demonstrationsposterna läggs till som dubbletter.
